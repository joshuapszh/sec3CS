Secondary 3 Computer Science Practice

Sec 3 classroom mocks based on topics taught so far (through Chapter 8). These are not full Cambridge IGCSE 0478 exam papers. Each set is an original 75-mark practice paper with a 1 hour 45 minute timer.

How feedback works

After submitting the whole paper, compare your answers with the suggested answers. Multiple-choice and exact short answers receive automatic marks. Review longer written and code answers yourself.

Scope: Paper 1 covers Chapters 1–6 (computer systems). Paper 2 covers Chapters 7–8 only (algorithms and programming, pseudocode). Topics beyond Chapter 8 (for example databases and Boolean logic in the full IGCSE Paper 2) are not included.
